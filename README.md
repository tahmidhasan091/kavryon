# Kavryon

Original user-generated multiplayer platform (Node + SQLite + Android WebView).

**Currency:** Kavx · **Creator Mode:** free · **Showcase game:** Crystal Siege

## Quick start
```bash
cd KAVRYON
cp .env.example .env
cd backend && npm install && node server.js
```

## Tests
```bash
cd backend && npm install && npm test
```

## Android
```bash
cd android && ./gradlew assembleDebug
```
See `android/BUILD_STATUS.md` and `.github/workflows/android-build.yml`.
